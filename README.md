# Sistema de Notificação

Uma página simples e com um visual moderno que demonstra a implementação de notificações (Toast Notifications) utilizando HTML, CSS puro com Glassmorphism e JavaScript básico.

## Funcionalidades

- **Design Premium:** Cores vibrantes (gradient), modo escuro agradável e efeito de "glassmorphism" no container principal.
- **Micro-interações:** Botão com efeitos interativos (hover/active).
- **Notificação Toast:** Ao clicar no botão, uma notificação animada desliza para a tela a partir da lateral e desaparece automaticamente após 3 segundos.

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript Vanilla

## Como usar

1. Abra o arquivo `teste/index.html` no seu navegador de preferência.
2. Clique no botão "Mostrar Notificação".
3. Uma notificação toast aparecerá no canto inferior direito.
